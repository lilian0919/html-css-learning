💭 學習心得

📌 學習心得

  • 透過這次自主學習，我了解到一個網站從架構建立到外觀設計的製作流程， 也對前端網頁開發有了初步認識。
  • 在學習 HTML 的過程中，我了解 HTML 負責建立網頁的內容與結構； 而 CSS 則能調整網頁的樣式，使網站更加美觀與容易閱讀。
  • 透過實際製作網站，我不只是學習語法，也培養了規劃、設計與解決問題的能力。

📌 產生的興趣

  • 製作網頁的過程讓我發現程式設計不只是輸入程式碼， 更像是在設計一個可以被使用的作品。
  • 看到自己撰寫的程式逐漸變成完整網站， 讓我對網頁設計與前端開發產生更大的興趣。
  • 我開始對網站的版面設計、使用者操作體驗以及互動效果感到好奇。

📌 未來展望

  • 未來希望繼續學習 JavaScript，讓網站加入更多互動功能。
  • 進一步學習 RWD（響應式網頁設計），讓網站能在手機、平板與電腦上正常顯示。
  • 嘗試學習更多網頁設計工具與技術，提升自己的網站製作能力。
  • 持續累積作品，建立自己的網頁作品集。
