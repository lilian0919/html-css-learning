📅 學習計畫與目標

📌 四週學習計畫

週次 學習內容 預計完成目標
第一週 認識 HTML 基本架構
學習常用標籤 		能建立基本網頁架構， 了解標題、文字、圖片與連結的使用方式。
第二週 學習 CSS 基礎語法
調整文字、顏色與版面 		能利用 CSS 美化網頁， 讓網站具有基本設計感。
第三週 實際製作網站
設計各個網頁內容 		完成首頁、學習內容、練習過程等頁面。
第四週 修改網站細節
改善排版與使用體驗 		完成完整網站， 並整理學習成果與心得。

🎯 希望達成的效果

  • 了解 HTML 與 CSS 在網頁製作中的功能與差異。
  • 能夠獨立建立一個簡單且完整的網站。
  • 學會基本網頁排版與美化技巧。
  • 培養自主查找資料與解決問題的能力。
  • 對前端網頁設計產生興趣，作為未來學習方向。
