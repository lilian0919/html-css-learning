HTML 是什麼？

HTML（HyperText Markup Language，超文字標記語言）是建立網頁內容與架構的語言，可以建立標題、文字、圖片、超連結等內容，是製作網站最基礎的技術。

HTML 常用標籤

標籤 功能
<h1>~<h6> 建立標題
<p> 建立段落
<br> 換行
<hr> 水平分隔線
<a> 建立超連結
<img> 插入圖片
<ul>、<li> 建立清單
<table> 建立表格
<div> 建立區塊，方便排版

CSS 是什麼？

CSS（Cascading Style Sheets，層疊樣式表）主要負責網頁的外觀設計，例如文字大小、背景顏色、版面配置、圖片位置與動畫效果，讓網頁更加美觀且容易閱讀。

CSS 常用屬性

CSS 屬性 功能
color 文字顏色
background-color 背景顏色
font-size 文字大小
width / height 設定寬度、高度
border 加入邊框
margin 設定外距
padding 設定內距
display 設定排列方式
border-radius 圓角效果
box-shadow 陰影效果
transition 動畫效果
:hover 滑鼠移入效果
